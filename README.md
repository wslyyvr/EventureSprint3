# EventureSprint3

## Overview

EventureSprint3 is a community event registration and management web application built with React.
The application allows users to create an account, register for community events, and manage the events they plan to attend.

This project simulates a system used by a community activity center to organize and manage local events.

## Features

* User registration
* Browse available community events
* Register for events
* Manage registered events
* Edit or update event attendance

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* Git & GitHub

## Installation

1. Clone the repository

```
git clone https://github.com/wslyvr/EventureSprint3.git
```

2. Install dependencies

```
npm install
```

3. Run the project

```
npm start
```

## Project Purpose

This project demonstrates the development of a modern web application using the React framework.
It focuses on user interaction, event registration functionality, managing user participation in community events, 
and supporting responsive display across multiple screen sizes.
